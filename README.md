# Crab-Allometry-Initiative
R code for analyzing red king crab allometry data. Data was collected in Southeast Alaska

Author: Alexandra Reich, alex.reich@alaska.gov, and others.


Phase 1 of the analysis (correlations and linear models) is in "Allometry Code AGR cleanup". This is Spencer's original analysis with Alex's add ons.

(Phase 2) "Coxa measure test.R" contains the coxa measurement test analysis. Chris Siddon and the Trooper(s) set calipers to 31 mm, 32 mm, and 33 mm and tested if those coxa measurements called the crab legal or not legal, and compared that to the crab's actual legality using a crab stick.

(Phase 3) "Phase_3_port_sampling.R" contains the port sampling analysis. This code analyzes the data collected from the port sampling effort in Juneau, Alaska.

"Table 1 and other things.R" creates additional figures and tables for the manuscript.

"Appendix_A_pilot_data.R" runs the analysis for Appendix A, which uses the pilot data from 2017.
